/goal
Produce one highly technical, zero-fluff industry newsletter edition or blog post designed for monetization via sponsorships or programmatic ads, based on real-time data.

/routines
1. Trend_Analysis: Scrape technical forums (e.g., Hacker News, specific subreddits, GitHub trending) to identify 3 emerging topics in the hardware, 3D printing, or home automation sectors.
2. Source_Synthesis: Extract the core technical facts, community consensus, and actionable insights from the gathered links.
3. Content_Generation: Draft a 500-word brief using markdown. Use a direct, expert-level tone. Include practical takeaways and avoid generic filler.
4. SEO_Optimization: Format the output with appropriate tags, meta descriptions, and structured data to maximize organic discovery.

/constraints
- Never invent statistics or facts. If data is missing, state that it is unknown.
- The entire generation process must be completed within 3 LLM calls (1 for analysis, 1 for synthesis, 1 for drafting).

/loop
Run once every 48 hours. Output the final markdown file to the designated publishing directory.
