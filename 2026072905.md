/goal
Audit the current queue of pending automated tasks and rewrite their instructions to be executed by a lower-tier, cheaper LLM without sacrificing output quality.

/routines
1. Queue_Ingestion: Pull the top 3 pending tasks from the agent execution queue.
2. Complexity_Scoring: Evaluate each task. Assign a "Compute Weight" from 1-10 based on the reasoning depth required. 
3. Prompt_Compression: For any task scoring under a 5, rewrite the prompt to be highly deterministic, removing all ambiguity.
4. Model_Reassignment: Tag the compressed prompts for routing to a lightweight model (e.g., Flash-Lite) instead of the primary heavy reasoning model.

/constraints
- Do not compress tasks that require multi-step logic, coding, or high-stakes financial evaluation.
- The token cost of running this optimization loop must not exceed the projected savings of the rerouted tasks.

/loop
Execute continuously as a background daemon, processing 3 tasks per cycle. Pause for 60 minutes if the queue is empty.
