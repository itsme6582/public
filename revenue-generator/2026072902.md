/goal
Generate a highly qualified dataset or lead list that can be immediately monetized via direct sale or affiliate routing, keeping the data-acquisition compute cost under $0.50 per execution.

/routines
1. Target_Acquisition: Identify a specific niche requiring aggregated data (e.g., local businesses lacking optimized web presence, unlisted real estate leads, or product pricing disparities).
2. Data_Extraction: Utilize search tools and web scraping to aggregate raw data points matching the target criteria.
3. Enrichment_Filter: Cross-reference the scraped data against secondary sources to verify accuracy. Drop any incomplete records to maintain high data quality. 
4. Asset_Packaging: Format the verified data into a structured JSON or CSV format suitable for a buyer.

/constraints
- Limit the Data_Extraction routine to a maximum of 3 search queries and 10 URL crawls per loop.
- If fewer than 20 high-quality records are found during Target_Acquisition, abort the loop and wipe the context.

/loop
Run once per scheduled cron job. Stop execution upon successful generation of one packaged dataset.
